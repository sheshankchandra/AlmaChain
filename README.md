Solana blockchain based degree registry project done for final year internship at NIT Silchar.

Built by Sheshank Chandra Pothu (1913128)
Guide: Dr. Malaya Dutta Borah (CSE Dept, NIT Silchar)

## Setup and Run
- Anchor version 0.24.2
- Solana devnet or localnet

```bash
cd app
npm install
npm start
```
